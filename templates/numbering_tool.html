About this tool

This tool adds custom page numbers to any PDF file. It uses the same powerful page numbering system as BunTool, including support for custom alphanumeric numbering and page range mapping.

Features:

  • Multiple numbering styles (Page 1, 1/100, A1, B2, etc.)
  • Four font options (Sans, Serif, Mono, Charter)
  • Alignment control (Left, Centre, Right)
  • Custom alphanumeric prefixes (A, B, Doc, etc.)
  • Page range mapping (pages 1-20 as A1-A20, pages 21-40 as B1-B20, etc.)
  • Optional footer prefix

Free, open-source, and private. All files are automatically deleted after processing.
